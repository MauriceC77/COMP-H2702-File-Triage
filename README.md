# COMP H2702 – File Triage Project

## Description
A Python program that scans files, calculates SHA-256 hashes, compares them with a reference list, and identifies duplicates.

## Setup
- Python 3 is required.
- No additional packages are needed.
- Keep the project files together.

## How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Type `python file_triage.py` and press Enter.
4. Press Enter to scan the default samples folder.

## Project Files
- `file_triage.py` – Main Python program.
- `samples/` – Test files.
- `hashes_reference.csv` – Reference hashes.
- `triage_report.json` – Saved results.
